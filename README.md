# HivePic

[HivePic](https://hivepic.com/) — Free online AI image editor: crop, rotate and adjust light in your browser, then remove a background, watermark or blur with AI. No sign-up.

## Official website

**[HivePic](https://hivepic.com/)**

## Mini tool (in this repo)

Open [`tools/index.html`](tools/index.html) for a tiny browser helper (Brightness preview). It runs locally in your browser and links out to the live site.
